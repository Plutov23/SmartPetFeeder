# SmartPetFeeder 从零复现教程

这套教程面向具备基础 C 语言知识、第一次尝试完整嵌入式项目的大学生。目标不是让读者复制一份“能编译的毕业设计”，而是理解每个模块为什么存在、如何验证，以及系统出现问题时应该怎样排查。

## 最终成果

完成全部章节后，你将搭建一台能够实现以下功能的原型机：

- 定时、定量出粮
- 手机远程手动喂食
- 温湿度和余粮重量监测
- OLED 本地状态显示
- 猫狗目标检测和进食状态判断
- 进食时长与消耗重量记录
- 微信小程序数据展示和局域网视频预览

## 推荐基础

开始前最好了解：

- C 语言变量、函数、结构体和数组
- GPIO 输入输出的基本概念
- 串口 TX、RX、波特率和共地
- 能够使用 Keil 创建、编译和烧录 STM32 工程
- 会使用万用表测量直流电压和通断

不要求提前掌握 MQTT、目标检测或微信小程序。相关概念会在对应章节解释。

## 教程约定

每一章都采用相同结构：

1. 本章目标
2. 原理说明
3. 硬件或软件准备
4. 分步骤实现
5. 预期现象
6. 验证清单
7. 常见错误

出现问题时，不要同时修改多个模块。先确认电源，再确认单个模块，最后检查模块之间的通信。

## 安全与隐私

- 不要把真实 Wi-Fi 密码、OneNET Token、微信 AppID 密钥提交到 Git。
- 电机必须经过驱动模块供电，禁止直接连接 STM32 GPIO。
- 不确定模块电压时，先查阅所购买板卡的官方资料。
- 更改接线前先断电。
- 原型机不应在无人看管时长期运行。

## 获取代码

克隆仓库：

```bash
git clone https://github.com/Plutov23/SmartPetFeeder.git
cd SmartPetFeeder
```

正式教程版本发布后，每一阶段会提供对应的 Git Tag。读者可以通过以下方式切换到指定版本：

```bash
git tag
git switch --detach <tag-name>
```

返回最新代码：

```bash
git switch main
```
