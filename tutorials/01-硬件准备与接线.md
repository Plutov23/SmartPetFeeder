# 第 1 章：硬件准备与接线

## 本章目标

完成本章后，你应该能够：

- 准备项目所需的主要模块和调试工具
- 区分 3.3 V 逻辑、电机电源和模块供电
- 按照引脚表完成基础接线
- 使用分阶段方式降低一次性联调难度
- 在通电前完成安全检查

本章只完成硬件准备和接线，不要求所有模块立即工作。

## 2. 调试工具

建议准备：

- 数字万用表
- 杜邦线和面包板
- 小螺丝刀
- USB 转串口模块
- ST-Link
- 可调电源或带电流显示的 USB 电源表
- 标签纸或不同颜色的导线

万用表至少需要会使用直流电压档和蜂鸣通断档。

## 3. 供电设计原则

### 所有模块必须共地

不同电源可以分别给电机、MaixCam 和 STM32 供电，但它们的 GND 必须连接在一起，否则 UART 和 GPIO 没有共同的电压参考。

```text
5 V 电源 GND ─┐
3.3 V 电源 GND ├── 公共 GND
STM32 GND ─────┤
MaixCam GND ───┘
```

### GPIO 不能直接驱动电机

STM32 GPIO 只能输出逻辑信号，不能直接为 28BYJ-48 供电。必须使用 ULN2003 驱动板：

```text
STM32 GPIO → ULN2003 输入 → ULN2003 功率输出 → 28BYJ-48
```

### ESP-01S 需要稳定电源

ESP-01S 发射 Wi-Fi 时会产生明显的瞬时电流。如果电源能力不足，常见现象包括：

- 不断重启
- 连接热点后立即掉线
- 发送 MQTT 数据时复位
- 串口出现乱码或异常启动日志

不要用供电能力不足的 USB 转串口模块直接给 ESP-01S 供电。

### 先测电压，再接模块

每次修改电源模块后：

1. 不连接负载
2. 使用万用表测量输出
3. 确认极性和电压
4. 断电
5. 再连接模块

## 5. 串口接线

串口 TX 和 RX 必须交叉连接：

```text
设备 A TX → 设备 B RX
设备 A RX ← 设备 B TX
设备 A GND ─ 设备 B GND
```

### 调试串口

| STM32 | USB 转串口 |
| --- | --- |
| PA9 TX | RX |
| PA10 RX | TX |
| GND | GND |

打开串口工具时选择 9600 baud、8 数据位、无校验、1 停止位。

### MaixCam

| STM32 | MaixCam |
| --- | --- |
| PA2 TX | RX |
| PA3 RX | TX |
| GND | GND |

实际使用中主要是 MaixCam 向 STM32 发送识别结果，但仍建议预留双向串口。

### ESP-01S

| STM32 | ESP-01S |
| --- | --- |
| PB10 TX | RX |
| PB11 RX | TX |
| GND | GND |

ESP-01S 的 EN/CH_PD 必须按照模块要求拉高。裸模块还需要考虑启动模式引脚，使用带底板的 ESP-01S 模块会更容易调试。

## 6. 传感器与显示接线

### AHT20

| AHT20 | STM32 |
| --- | --- |
| SCL | PB8 |
| SDA | PB9 |
| GND | GND |
| VCC | 按模块规格供电 |

I2C 总线通常需要上拉电阻，很多模块板已经集成。不要在不了解模块电路时重复并联过小的上拉电阻。

### OLED

| SSD1306 OLED | STM32 |
| --- | --- |
| SCL | PB13 |
| SDA | PB14 |
| GND | GND |
| VCC | 按模块规格供电 |

本项目使用软件 I2C，OLED 和 AHT20 不在同一组引脚上。

### DS1302

| DS1302 | STM32 |
| --- | --- |
| RST / CE | PA4 |
| CLK / SCLK | PA5 |
| DAT / IO | PA6 |
| GND | GND |
| VCC | 按模块规格供电 |

不同模块可能使用 `RST`、`CE` 等不同标注，连接前确认模块丝印。

### HX711

| HX711 | STM32 |
| --- | --- |
| DT / DOUT | PA11 |
| SCK / CLK | PA12 |
| GND | GND |
| VCC | 按模块和电平要求供电 |

压力传感器接到 HX711 的激励端和差分输入端。不同颜色导线没有统一标准，应根据传感器资料或实测确认。

## 7. 电机接线

| ULN2003 | STM32 |
| --- | --- |
| IN1 | PB4 |
| IN2 | PB5 |
| IN3 | PB6 |
| IN4 | PB7 |
| GND | 公共 GND |
| VCC | 5 V 电机电源 |

28BYJ-48 使用原配插头连接 ULN2003。第一次测试时不要安装出粮机构，先观察电机空载方向和运行状态。

## 8. 推荐分阶段接线

不要一次连接全部模块。推荐按以下阶段进行：

### 阶段 A：主控与日志

只连接：

- STM32
- ST-Link
- USB 转串口

目标：能够烧录程序并看到启动日志。

### 阶段 B：低功耗传感器

依次增加：

1. OLED
2. AHT20
3. DS1302
4. HX711

每增加一个模块，都先确认上一个模块仍然正常。

### 阶段 C：电机

增加 ULN2003、独立 5 V 电源和 28BYJ-48。首次测试应空载运行，并观察电源电压是否明显下降。

### 阶段 D：网络

增加 ESP-01S。先使用串口工具单独测试 AT 指令，再连接 STM32。

### 阶段 E：视觉

最后连接 MaixCam。先让 MaixCam 向串口工具发送状态，再接入 STM32 USART2。

## 9. 通电前检查清单

- [ ] 所有模块 GND 已共地
- [ ] 3.3 V 和 5 V 没有接反
- [ ] STM32 GPIO 没有直接连接电机
- [ ] ESP-01S 供电能力足够
- [ ] TX 和 RX 已交叉连接

- [ ] 电机首次测试为空载
- [ ] 上电前已用万用表测量稳压输出

## 10. 常见错误

### 串口完全没有数据

- TX/RX 没有交叉
- 忘记共地
- 波特率错误
- USB 转串口电平不匹配

### 一启动电机系统就重启

- 电机和 MCU 使用同一弱电源
- 电机堵转
- 电源线压降过大
- 没有做好公共地和电源去耦

### I2C 模块没有响应

- SCL/SDA 接反
- 模块地址与代码不一致
- 缺少上拉电阻
- 模块供电电压错误

### HX711 数值跳动严重

- 压力传感器固定不牢
- 线缆受到拉扯
- 电机噪声耦合到称重线路
- 电源纹波较大
- 没有预热、去皮和滤波
