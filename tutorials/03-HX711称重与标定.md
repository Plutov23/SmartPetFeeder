# 第 3 章：HX711 称重、去皮与标定

## 本章目标

完成本章后，你应该能够：

- 解释称重传感器、HX711 和 STM32 的分工
- 读取 24 位原始数据
- 完成空载去皮
- 使用已知砝码计算比例系数
- 判断重量方向、零点漂移和机械干扰
- 验证称重结果是否适合喂食器使用

## 1. 称重链路

本项目的称重链路：

~~~text
重量
  ↓
应变式称重传感器
  ↓ 微弱差分电压
HX711 放大与 24 位模数转换
  ↓ DOUT/SCK
STM32 原始值、去皮与比例换算
  ↓
克数
~~~

称重传感器负责把形变转换为电信号，HX711 负责放大和数字化，STM32 负责把原始计数换算成克。

## 2. 硬件准备

- 与结构匹配的称重传感器
- HX711 模块
- 稳定的电源
- 一个已知重量的砝码
- 能固定传感器和料斗的机械结构

砝码最好位于传感器量程的 20% 至 80%。过轻时误差占比大，超过额定量程可能永久损坏传感器。

## 3. 接线

HX711 与 STM32：

| HX711 | STM32 | 说明 |
| --- | --- | --- |
| VCC | 按模块要求供电 | 先确认模块允许电压 |
| GND | GND | 必须共地 |
| DOUT/DT | PA11 | 数据输入 |
| SCK/CLK | PA12 | 时钟输出 |

称重传感器连接 HX711 的 E+、E-、A+、A-。不同厂家的线色可能不同，应以传感器数据手册或实测结果为准，不要只按网络图片的颜色接线。

机械安装要求：

- 固定端必须牢固
- 受力端只能通过设计的方向受力
- 线缆不能拉扯受力端
- 料斗不能碰到外壳
- 电机振动不能直接传递到传感器

机械结构不稳定时，软件滤波无法从根本上解决问题。

## 4. 驱动如何读取数据

代码位于：

- <code>firmware/stm32f103/Core/Inc/HX711.h</code>
- <code>firmware/stm32f103/Core/Src/HX711.c</code>

当 DOUT 变为低电平，表示一次转换完成。驱动产生 24 个时钟脉冲并逐位读取数据，再产生第 25 个脉冲，选择 A 通道、128 倍增益。

核心流程：

~~~text
SCK 拉低
  ↓
等待 DOUT 拉低
  ↓
读取 24 位数据
  ↓
发送第 25 个脉冲
  ↓
转换数据格式并返回
~~~

当前实现使用阻塞等待：

~~~c
while (HAL_GPIO_ReadPin(HX711_DAT_PORT, HX711_DAT_PIN) == GPIO_PIN_SET)
    ;
~~~

如果 HX711 断线、未供电或 DOUT 始终为高，程序会停在这里。教学阶段可以借此判断接线问题，后续工程化时应增加超时和错误返回。

## 5. 去皮是什么意思

料斗、托盘和安装件本身都有重量。去皮就是把当前空载原始值记录为零点：

~~~text
Offset = 空载原始值的平均值
~~~

项目在 <code>HX711_Init()</code> 中：

1. 丢弃前两次读数
2. 连续读取 10 次
3. 计算平均值
4. 保存到 <code>HX711_Offset</code>

因此开机去皮时，料斗必须处于你定义的“零重量”状态。不要在料斗已有宠物粮时复位，否则这部分重量会被当成零点。

启动日志会显示：

~~~text
[WEIGHT] Manual taring start... Please keep the bowl empty.
[WEIGHT] Tare done! New Offset: ...
~~~

## 6. 重量换算公式

项目使用：

~~~text
重量(g) = (当前原始值 - 零点原始值) / 比例系数
~~~

对应代码中的变量：

| 变量 | 含义 |
| --- | --- |
| <code>raw_data</code> | 当前 HX711 原始值 |
| <code>HX711_Offset</code> | 空载零点 |
| <code>HX711_Scale</code> | 每克对应的原始计数 |
| <code>weight</code> | 换算后的克数 |

比例系数不能照抄别人的数值。传感器量程、供电、安装方向和机械结构不同，结果都会不同。

## 7. 单点标定步骤

### 第一步：预热

上电后保持结构静止 1 至 3 分钟。等待电源、传感器和机械应力趋于稳定。

### 第二步：空载去皮

清空料斗并复位开发板。记录日志中的 <code>HX711_Offset</code>，记为 O。

### 第三步：观察原始值

标定期间可以在 <code>HX711_Get_Weight()</code> 读取原始值后临时增加日志：

~~~c
APP_LOG(
    "WEIGHT",
    "Raw: %ld Offset: %ld",
    raw_data,
    HX711_Offset
);
~~~

重新编译并烧录。空载时观察读数是否稳定，再放上已知重量的砝码。

不要长期保留高频原始值日志，以免占用串口和主循环时间。

### 第四步：采集已知重量

准备已知重量 M 克的砝码：

1. 将砝码放在实际使用的受力位置。
2. 等待数值稳定。
3. 记录至少 10 个原始值。
4. 去掉明显异常值。
5. 计算平均值，记为 R。

### 第五步：计算比例系数

~~~text
HX711_Scale = (R - O) / M
~~~

如果放上重量后原始值减小，计算结果会是负数。这是正常的方向差异，可以使用负比例系数，也可以调整传感器差分输入方向。

### 第六步：写入系数

在 <code>Core/Src/HX711.c</code> 中更新：

~~~c
float HX711_Scale = 420.0f;
~~~

将 <code>420.0f</code> 替换为你计算得到的实际数值，删除临时原始值日志，然后重新编译和烧录。

## 8. 验证标定结果

不要只用标定时的一个重量验证。至少测试：

| 测试点 | 目的 |
| --- | --- |
| 空载 | 检查是否接近 0 g |
| 较轻重量 | 检查低量程灵敏度 |
| 标定重量 | 检查标定点 |
| 接近实际最大粮量 | 检查常用范围误差 |
| 移除再放回 | 检查重复性 |

建议记录：

~~~text
误差 = 显示重量 - 真实重量
相对误差 = 误差 / 真实重量 × 100%
~~~

喂食器更关心实际使用区间的重复性。即使全量程并非完全线性，也应保证常用粮量区间误差可接受。

## 9. 如何判断问题来源

### 始终卡在初始化

- HX711 没有供电
- DOUT 和 SCK 接反
- PA11、PA12 接线错误
- 没有共地
- HX711 模块损坏

### 放上重量仍显示 0 g

- 比例系数方向错误，计算结果为负后被代码限制为 0
- 传感器 A+、A- 接反
- 去皮时砝码没有移除
- 料斗没有真正把力传给传感器

### 显示值偏大或偏小

- 比例系数绝对值太小，显示值偏大
- 比例系数绝对值太大，显示值偏小
- 标定砝码重量不准确
- 标定位置与实际受力位置差异过大

### 数值持续跳动

- 电源纹波大
- 电机与 HX711 共用噪声严重的供电路径
- 传感器或料斗固定不牢
- 线缆拉扯传感器
- 电机运行时产生机械振动
- 当前运行时没有做多点平均或中值滤波

### 零点随时间漂移

- 上电后没有预热
- 环境温度变化
- 机械结构存在缓慢回弹
- 传感器长期承受偏载
- 电源基准不稳定

## 10. 当前实现的边界

当前驱动适合教学原型，但存在几个明确限制：

- 等待 DOUT 时没有超时
- 开机去皮假设料斗处于空载状态
- 运行时每次只使用一个样本，没有中值或滑动平均滤波
- 比例系数写在源码中，没有保存到 Flash
- 负重量直接限制为 0，可能掩盖方向或零点问题

后续可改进为：

1. 增加读取超时和错误码
2. 使用中值滤波去除脉冲干扰
3. 使用滑动平均降低随机噪声
4. 将零点和比例系数保存到 Flash
5. 增加按键或小程序远程去皮
6. 在电机运行结束并等待结构稳定后再采样
