# 第 4 章：步进电机与出粮标定

## 本章目标

完成本章后，你应该能够：

- 正确连接步进电机驱动板
- 解释 TIM3 如何产生步进节拍
- 调整电机方向和速度
- 用实际出粮重量计算每克步数
- 分别验证手动出粮和定时出粮
- 判断卡粮、打滑、供电不足和参数错误

## 1. 为什么需要驱动板

STM32 GPIO 只能输出逻辑电平，不能直接为步进电机线圈供电。本项目通过 ULN2003 一类驱动板放大电流：

~~~text
STM32 PB4~PB7
      ↓ 控制信号
   ULN2003
      ↓ 线圈电流
   步进电机
~~~

禁止把电机线圈直接连接 GPIO。电机电源与 STM32 逻辑电源可以分开，但两侧 GND 必须连接。

## 2. 接线

| 驱动板 | STM32 |
| --- | --- |
| IN1 | PB4 |
| IN2 | PB5 |
| IN3 | PB6 |
| IN4 | PB7 |
| GND | GND |
| VCC | 按电机与驱动板规格供电 |

第一次测试前：

1. 断开出粮机构，只测试空载电机。
2. 确认驱动板和电机额定电压。
3. 确认电机电源能提供足够电流。
4. 确认机构没有卡死。
5. 准备随时断电。

## 3. 驱动结构

代码位于：

- <code>Core/Inc/stepper_motor.h</code>
- <code>Core/Src/stepper_motor.c</code>
- <code>Core/Src/tim.c</code>

当前驱动使用四拍单相全步序列：

~~~text
0001 → 0010 → 0100 → 1000
~~~

顺序正向遍历为一个方向，反向遍历为另一个方向。不同电机和驱动板的线序可能不同，如果电机只抖动不转，应先核对 IN1 到 IN4 的顺序。

## 4. TIM3 如何控制速度

系统时钟为 72 MHz。TIM3 的预分频值为 71，因此计数器每 1 微秒计数一次。

<code>StepperMotor_SetSpeed()</code> 修改自动重装值：

~~~text
中断周期 = speed_us 微秒
~~~

驱动将速度限制在：

| 参数 | 数值 |
| --- | ---: |
| 最快节拍 | 500 μs/步 |
| 最慢节拍 | 5000 μs/步 |
| 默认调用值 | 2000 μs/步 |

数值越小，步进越快。速度过快时，电机可能失步、只响不转或出粮量变少。

## 5. 非阻塞步数控制

调用：

~~~c
StepperMotor_Step(total_steps);
~~~

函数只设置剩余步数并启动 TIM3 中断，不会在主循环里逐步等待。每次定时器中断：

1. 计算下一个相位
2. 更新 PB4 到 PB7
3. 将剩余步数减一
4. 步数归零后停止定时器
5. 拉低全部线圈，减少发热

因此电机运行期间，主循环仍可处理串口、传感器和 OLED。

## 6. 第一次空载测试

在确认驱动板接线后，可临时在初始化完成位置调用：

~~~c
StepperMotor_SetDirection(CLOCKWISE);
StepperMotor_SetSpeed(2000);
StepperMotor_Step(200);
~~~

烧录后观察：

- 电机是否连续转动
- 四路指示灯是否按顺序变化
- 停止后线圈是否释放
- STM32 是否因电源压降复位

验证完成后删除临时代码，避免每次上电自动转动。

## 7. 调整方向

如果出粮机构反转：

~~~c
StepperMotor_SetDirection(COUNTER_CLOCKWISE);
~~~

也可以调整电机线序，但软件改方向更容易复现。确定机械方向后，应在手动出粮和定时出粮两条路径中保持一致。

## 8. 为什么不能直接使用理论步数

理论步数只能描述电机轴转动，实际出粮还受到以下因素影响：

- 减速箱传动误差
- 螺杆或叶轮尺寸
- 宠物粮颗粒大小和形状
- 粮仓填充高度
- 料道摩擦
- 电机失步
- 粮粒卡住或架桥

所以最终参数必须通过真实宠物粮称重得到。

## 9. 每克步数标定

### 准备

- 完成 HX711 标定
- 使用实际粮仓和实际宠物粮
- 清理出粮口
- 选择不会使电机失步的速度
- 准备记录至少 5 次试验

### 单次试验

1. 记录出粮前重量。
2. 执行固定步数 N。
3. 等待粮粒停止掉落。
4. 记录出粮后重量。
5. 计算实际出粮重量 W。

~~~text
每克步数 = N / W
~~~

不要只测一次。对多个固定步数和目标重量重复测试，计算平均值。

### 推荐记录表

| 次数 | 步数 N | 实际重量 W | N/W |
| ---: | ---: | ---: | ---: |
| 1 |  |  |  |
| 2 |  |  |  |
| 3 |  |  |  |
| 4 |  |  |  |
| 5 |  |  |  |

如果低重量误差明显，可以增加最小出粮量，或建立带截距的标定模型，而不是假设所有重量都严格线性。

## 10. 写入标定值

手动出粮使用本地配置：

~~~c
#define FEEDER_STEPS_PER_GRAM 50
~~~

文件位置：

~~~text
firmware/stm32f103/Core/Inc/app_config.h
~~~

将 50 替换为你的实测值。

当前定时计划模块在 <code>schedule.c</code> 中还保留了独立的 <code>STEPS_PER_GRAM 50</code>。因此当前版本需要让两个值保持一致，否则手动出粮与定时出粮会产生不同重量。这是后续应统一配置的已知限制。

## 11. 验证两条出粮路径

### 手动出粮

小程序下发 <code>feed_amount</code> 后：

~~~text
目标克数 × FEEDER_STEPS_PER_GRAM → 电机步数
~~~

### 定时出粮

DS1302 时间与计划匹配后：

~~~text
计划克数 × STEPS_PER_GRAM → 电机步数
~~~

分别测试 5 g、20 g、50 g 等实际使用范围，记录平均误差和最大误差。

## 12. 常见问题

### 电机只抖动

- IN1 到 IN4 顺序错误
- 电机电源电流不足
- 速度过快
- 机械负载过大

### 电机转动时 STM32 重启

- 电机和逻辑电路共用弱电源
- 电源线压降过大
- 驱动板附近缺少去耦
- 接地路径不合理

### 步数正确但出粮越来越少

- 电机失步
- 粮道堵塞
- 粮粒架桥
- 粮仓余量影响填充
- 叶轮打滑

### 电机停止后发热

- 停止函数没有执行
- 某些输出仍保持高电平
- 机构持续堵转
- 电机或供电规格不匹配

### 大重量命令行为异常

当前剩余步数使用 <code>uint16_t</code>。目标重量与每克步数的乘积不能超过该类型可表示范围，应在上层限制命令范围。
