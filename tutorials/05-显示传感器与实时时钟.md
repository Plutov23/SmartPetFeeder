# 第 5 章：显示、传感器与实时时钟

## 本章目标

完成本章后，你应该能够：

- 区分 OLED 软件 I2C 与 AHT20 硬件 I2C
- 显示当前时间和余粮百分比
- 读取 AHT20 温湿度
- 设置并读取 DS1302 时间
- 判断显示、传感器和时钟分别是否正常

## 1. 三个模块的分工

| 模块 | 作用 | 接口 |
| --- | --- | --- |
| SSD1306 OLED | 本地显示时间和余粮 | 软件 I2C |
| AHT20 | 环境温湿度 | 硬件 I2C1 |
| DS1302 | 断电保持实时时间 | 三线 GPIO |

三个模块应先单独验证，再同时接入。

## 2. 接线总表

### OLED

| OLED | STM32 |
| --- | --- |
| SCL | PB13 |
| SDA | PB14 |
| GND | GND |
| VCC | 按模块规格供电 |

### AHT20

| AHT20 | STM32 |
| --- | --- |
| SCL | PB8 |
| SDA | PB9 |
| GND | GND |
| VCC | 按模块规格供电 |

I2C1 已重映射到 PB8 和 PB9，速率为 100 kHz。

### DS1302

| DS1302 | STM32 |
| --- | --- |
| RST/CE | PA6 |
| CLK/SCLK | PA4 |
| DAT/IO | PA5 |
| GND | GND |
| VCC | 按模块规格供电 |

当前驱动的实际宏定义位于 <code>Core/Inc/ds1302.h</code>。部分 CubeMX 标签和旧注释的命名顺序不同，接线时以驱动宏为准。

## 3. OLED 软件 I2C

OLED 驱动直接控制 PB13 和 PB14，不使用 <code>hi2c1</code>。这样 OLED 与 AHT20 可以分别排查，不共享同一组总线引脚。

初始化流程：

~~~text
OLED_Init
  ↓
OLED_Clear
  ↓
OLED_Update
~~~

主页每秒刷新一次，显示：

- DS1302 当前时间
- 余粮百分比
- 图形进度条

余粮百分比计算：

~~~text
百分比 = 当前重量 / 最大粮量 × 100%
~~~

当前 <code>OLED_Menu.c</code> 将最大粮量固定为 500 g。实际粮仓容量不同，应修改 <code>MAX_FOOD_WEIGHT</code> 并重新验证。

内置 OLED 驱动使用最小 ASCII 字形集。需要显示新的字符时，应在 <code>OLED.c</code> 中补充对应字形。

## 4. AHT20 硬件 I2C

AHT20 使用 I2C1：

~~~text
PB8  → I2C1_SCL
PB9  → I2C1_SDA
100 kHz
~~~

驱动使用 HAL 所需的左移后地址 <code>0x70</code>。这对应常见文档中的 7 位地址 <code>0x38</code>，两种写法不要混淆。

读取流程：

1. 发送测量命令 <code>AC 33 00</code>
2. 等待至少 75 ms
3. 读取 6 字节
4. 检查忙状态
5. 换算 20 位湿度和温度数据

主循环每 5 秒读取一次，并输出：

~~~text
[AHT20] Read Success - Temp: ... C, Humi: ... %
~~~

## 5. DS1302 与 BCD 时间

DS1302 使用三线接口，不是 I2C。时间寄存器采用 BCD 编码。例如十进制 26 会保存为十六进制形式的 <code>0x26</code>。

驱动负责：

- 十进制转 BCD 后写入
- 读取 BCD 并转回十进制
- 保存当前时、分、秒
- 输出完整日期时间日志

主循环每秒调用一次：

~~~c
DS1302_ReadAndPrintTime();
~~~

随后将时、分传给定时喂食模块。

## 6. 首次设置时间

在 <code>main.c</code> 初始化区域有一行示例调用：

~~~c
// DS1302_SetTime(26, 4, 11, 17, 30, 10);
~~~

参数依次为：

~~~text
年、月、日、时、分、秒
~~~

首次使用步骤：

1. 根据当前时间填写参数。
2. 临时取消注释。
3. 编译并烧录一次。
4. 确认日志时间正确。
5. 再次注释该行并重新烧录。

如果一直保留设置调用，每次复位都会把时钟写回固定时间。

DS1302 模块应安装有效的后备电池。断开主电源后等待一段时间，再重新上电检查是否继续计时。

## 7. 分模块验证顺序

### 第一步：只验证 OLED

- 上电后屏幕能够点亮
- 时间区域和 FOOD 百分比可见
- 没有随机花屏

### 第二步：验证 AHT20

- 串口每 5 秒出现一次成功日志
- 手握传感器后温湿度变化方向合理
- 读数位于物理上可能的范围

### 第三步：验证 DS1302

- 串口每秒输出一次时间
- 秒数连续递增
- 断电重启后时间没有回到初始值

### 第四步：组合验证

- OLED 每秒刷新
- AHT20 每 5 秒读取
- DS1302 时间连续
- 三个模块同时工作时系统不复位

## 8. 预期运行节奏

~~~text
每 1 秒：
  DS1302 读取时间
  HX711 读取重量
  检查喂食计划
  OLED 刷新

每 5 秒：
  AHT20 读取温湿度
  上报 OneNET
~~~

OLED 显示的时间来自 DS1302，不是手机时间；余粮百分比来自 HX711，不是电机累计出粮量。

## 9. 常见问题

### OLED 不亮

- 检查供电和 GND
- 检查 PB13、PB14 是否接反
- 确认模块控制器和地址与驱动兼容
- 检查复位后是否执行 <code>OLED_Menu_Init()</code>

### OLED 花屏或闪烁

- 电源不稳定
- 接线过长
- 软件 I2C 时序受干扰
- 电机运行时噪声耦合

### AHT20 一直读取失败

- PB8、PB9 接反
- 总线没有上拉
- 模块供电错误
- 地址写法错误
- I2C 总线被其他设备拉低

### 温湿度长期为旧值

当前驱动在失败时保留上一次变量值。必须同时观察成功或失败日志，不能只看小程序上的数字。

### DS1302 时间不走

- 后备电池无电
- 秒寄存器停止位没有清除
- CLK、IO、RST 接错
- RST 没有在通信时正确拉高

### DS1302 时间每次复位都相同

- <code>DS1302_SetTime()</code> 仍在每次启动时执行
- 后备电池未安装或接触不良

## 10. 当前实现的边界

- OLED 最大粮量固定在源码中
- OLED 字库只覆盖当前所需的最小 ASCII 集
- AHT20 使用阻塞式 HAL 调用和 75 ms 延时
- AHT20 没有向上层返回明确错误码
- DS1302 设置时间需要临时修改源码
- 驱动注释与 CubeMX 旧标签存在历史差异
- 没有统一的传感器在线状态页面

后续可以将最大粮量、时钟设置和传感器状态做成可配置项。
