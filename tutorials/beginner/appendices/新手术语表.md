# 新手术语表

## AppID

微信小程序的项目身份编号。正式发布时使用自己的 AppID。

## API

软件之间互相请求数据的方法。小程序通过 API 向 OneNET 读取数据或发送命令。

## AT 命令

发送给 ESP-01S 的文字命令，例如连接 Wi-Fi、连接 MQTT。

## 波特率

串口双方约定的通信速度。两边必须一致，常见值有 9600 和 115200。

## 编译

把 C 代码转换成 STM32 能运行的程序。

## 烧录

把编译好的程序写入 STM32。

## 调试

通过日志、断点和测试，寻找程序没有按预期运行的原因。

## 驱动

有两种常见意思：

- 电脑驱动：让电脑识别 ST-Link 等设备
- 模块驱动代码：让 STM32 控制 OLED、传感器或电机

## GPIO

STM32 上可以读取或输出高低电平的普通引脚。

## GND

电路的公共参考点。通信模块通常必须共地。

## HAL

STM32 官方提供的一组函数，帮助程序控制 GPIO、串口、I2C 和定时器。

## I2C

一种传感器通信方式，主要使用 SCL 和 SDA 两根信号线。

## IP 地址

设备在网络中的地址。MaixCam 的 WebSocket 地址中会包含局域网 IP。

## JSON

一种组织数据的文字格式。OneNET 和 WebSocket 消息会使用 JSON。

## MQTT

物联网常用的消息通信方式。ESP-01S 使用 MQTT 与 OneNET 通信。

## OneNET

本项目使用的云平台，负责连接设备和微信小程序。

## 引脚

开发板上用于供电、输入、输出或通信的金属连接点。

## RX

Receive，接收数据。通常连接对方的 TX。

## TX

Transmit，发送数据。通常连接对方的 RX。

## UART / USART

STM32 的串口通信外设。本教程可以先把 UART 和 USART 都理解成串口。

## Token

设备连接云平台使用的凭据，作用类似密码，不能公开。

## Authorization

小程序调用 OneNET API 使用的授权信息，也不能公开。

## WebSocket

网页或小程序与设备保持持续连接的方法。本项目用它接收 MaixCam 画面。

## Wi-Fi

无线网络。本项目的 ESP-01S 通常连接 2.4 GHz Wi-Fi。

## 传感器

把温度、湿度、重量等现实信息转换成电信号或数字的模块。

## 执行器

真正产生动作的部件，例如步进电机和蜂鸣器。

## 去皮

把当前空料斗重量设为 0 g。

## 标定

使用已知标准，计算传感器数值与真实物理量之间的关系。

## 中断

硬件事件发生时，STM32 暂时处理紧急任务的方法，例如收到一个串口字节。

## 阻塞

程序停在一个步骤等待，暂时不能处理其他任务。长时间阻塞可能导致串口丢数据或页面更新变慢。
