| HX711 | 压力传感器 ADC | 1 | 有 E+/E-/A+/A- |

## 电源和接线

| 名称 | 用途 |
| --- | --- |
| 稳定 5 V 电源 | 电机和部分模块 |
| 稳定 3.3 V 电源 | ESP-01S、STM32 和传感器 |
| 杜邦线 | 模块连接 |
| 面包板 | 初期低电流实验 |
| 220 Ω～1 kΩ 电阻 | LED 限流 |
| LED | GPIO 学习实验 |
| 开关和保险保护 | 原型供电安全 |

不要让面包板长期承载电机大电流。

## 推荐工具

| 工具 | 用途 |
| --- | --- |
| 数字万用表 | 测量电压、通断和短路 |
| 小螺丝刀 | 固定端子 |
| 镊子 | 整理小连接件 |
| 扎带或线标 | 整理和标记线路 |
| 手机支架 | 拍摄教程和演示视频 |

有条件时可以使用示波器观察电源跌落和通信波形，但不是入门必需品。

## 购买前必须确认

- 模块工作电压
- 引脚名称和接口类型
- 电机额定电压
- 压力传感器量程
- ESP-01S 固件功能
- MaixCam 系统和模型兼容性
- 是否包含连接线、电池和驱动板

## 收到模块后

1. 拍摄正反面。
2. 记录模块型号。
3. 检查是否有损坏。
4. 标记 VCC 和 GND。
5. 不确定电压时先不要通电。
