# 常见错误速查表

## STM32 和 Keil

| 现象 | 先检查 |
| --- | --- |
| Keil 找不到设备 | STM32F1 Device Family Pack |
| 找不到编译器 | Target 选择的 ARM Compiler |
| 找不到 app_config.h | 是否复制模板到 Core/Inc |
| ST-Link 找不到开发板 | 供电、SWDIO、SWCLK、GND |
| 烧录成功但不运行 | 复位、系统时钟、Error_Handler |

## 串口

| 现象 | 先检查 |
| --- | --- |
| 完全没有文字 | 串口号、PA9、GND、是否复位 |
| 全是乱码 | 波特率是否 9600 |
| MaixCam 数据乱码 | 双方是否都是 9600 |
| ESP-01S 没响应 | USART3 是否 115200 |
| 偶尔正常 | 共地、供电和接触 |

## OLED 和传感器

| 现象 | 先检查 |
| --- | --- |
| OLED 不亮 | PB13、PB14、供电 |
| OLED 亮但无文字 | OLED_Update、字库、坐标 |
| AHT20 失败 | PB8、PB9、上拉和地址 |
| DS1302 时间不走 | PA6、PA4、PA5 和电池 |
| DS1302 每次回到同一时间 | 设置时间代码是否仍执行 |
| HX711 卡在初始化 | PA11、PA12、供电和共地 |
| 重量一直为 0 | 比例方向、去皮和机械安装 |
| 重量跳动 | 固定、电源、电机振动 |

## 电机

| 现象 | 先检查 |
| --- | --- |
| 只抖不转 | IN1～IN4 顺序、速度、供电 |
| 方向相反 | CLOCKWISE / COUNTER_CLOCKWISE |
| STM32 重启 | 电机电源、电压跌落、堵转 |
| 出粮不准 | 每克步数、卡粮、失步 |
| 停止后发热 | 是否调用 Stop、是否堵转 |

## Wi-Fi 和 OneNET

| 现象 | 先检查 |
| --- | --- |
| ESP-01S 重启 | 3.3 V 电源能力 |
| Wi-Fi 连接失败 | 2.4 GHz、名称、密码 |
| OneNET 不在线 | Product ID、Device Name、Token |
| 在线但没有数据 | 物模型标识符和 MQTT 响应 |
| 小程序一直为 0 | Authorization、设备信息、API 返回 |
| 下发成功但电机不动 | ESP 接收、STM32 日志、电机硬件 |

## MaixCam

| 现象 | 先检查 |
| --- | --- |
| 模型加载失败 | 路径、格式、系统版本、内存 |
| 看得到画面但识别不到 | 类别编号、光线、距离、阈值 |
| STM32 收不到状态 | TX/RX、GND、9600、串口设备 |
| 小程序没有视频 | IP、端口、同一局域网 |
| 状态频繁变化 | 机位、遮挡、阈值和防抖 |

## 固定排查顺序

~~~text
电源
  ↓
接线
  ↓
单个模块
  ↓
通信
  ↓
云平台
  ↓
小程序和业务逻辑
~~~
