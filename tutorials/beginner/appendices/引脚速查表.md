# STM32 引脚速查表

## 串口

| 用途 | STM32 引脚 | 波特率 |
| --- | --- | ---: |
| 电脑调试 USART1 | PA9 TX / PA10 RX | 9600 |
| MaixCam USART2 | PA2 TX / PA3 RX | 9600 |
| ESP-01S USART3 | PB10 TX / PB11 RX | 115200 |

串口通常交叉连接：TX 接对方 RX，RX 接对方 TX。

## 传感器和时钟

| 模块 | STM32 引脚 |
| --- | --- |
| AHT20 SCL | PB8 |
| AHT20 SDA | PB9 |
| HX711 DOUT | PA11 |
| HX711 SCK | PA12 |
| DS1302 RST | PA6 |
| DS1302 CLK | PA4 |
| DS1302 IO | PA5 |

## OLED

| OLED | STM32 |
| --- | --- |
| SCL | PB13 |
| SDA | PB14 |

OLED 使用软件控制的 I2C，与 AHT20 不共用引脚。

## 电机和提示

| 功能 | STM32 引脚 |
| --- | --- |
| ULN2003 IN1 | PB4 |
| ULN2003 IN2 | PB5 |
| ULN2003 IN3 | PB6 |
| ULN2003 IN4 | PB7 |
| 蜂鸣器 | PB12 |
| LED | PB15 |

## 供电提醒

- ESP-01S 使用稳定 3.3 V
- 本项目电机为 5 V 版本
- 电机必须经过驱动板
- 所有通信模块需要共地
- 不确认模块电压时不要通电
