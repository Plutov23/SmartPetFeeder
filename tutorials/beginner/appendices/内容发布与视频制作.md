# 教程内容发布与视频制作指南

## 核心原则：只维护一份母稿

零基础 Markdown 教程是内容母稿。

博客、小书、长视频和短视频都从母稿改编，不要分别独立创作四套内容。

推荐流程：

~~~text
Markdown 教程
  ↓
博客文章
  ↓
长视频脚本和画面清单
  ↓
短视频片段
  ↓
整理成小书章节
~~~

这样修改接线或代码时，只需要先更新母稿，再同步其他形式。

## 每一课需要保存的素材

| 素材 | 用途 |
| --- | --- |
| 完成效果照片 | 博客头图、视频开场、小书插图 |
| 接线全景 | 教程和长视频 |
| 接线近景 | 排障说明和短视频 |
| 屏幕录制 | Keil、OneNET、小程序操作 |
| 串口日志 | 成功现象和错误对照 |
| 失败案例 | 排障文章和短视频 |
| 测试数据 | 博客表格和答辩证据 |

每完成一课就拍摄，不要等项目全部完成后再补素材。

## 长视频怎么做

建议一课对应一个 6～15 分钟视频。

### 固定结构

1. 前 5 秒展示最终效果
2. 用一句话说明本期目标
3. 展示需要的模块
4. 展示接线
5. 展示代码或软件操作
6. 展示正确现象
7. 展示一个常见错误
8. 用检查清单结尾

### 示例开场

~~~text
这一期我们只做一件事：
让 STM32 控制 LED 闪烁。
完成后，你会知道什么是 GPIO，也会完成第一次烧录。
~~~

### 拍摄方法

- 硬件操作使用横屏
- 屏幕操作直接录屏，不要用手机拍电脑
- 接线近景要锁定焦点
- 先录画面，再单独录旁白也可以
- 环境噪声大时优先改善声音，而不是追求更贵的相机
- 重要步骤保留 2～3 秒静止画面

### 画面规格

- 长视频：优先 16:9 横屏
- 至少 1080p
- 屏幕录制保持文字清晰
- 不要在画面边缘放重要文字
- 保留无字幕原始素材，方便以后重新剪辑

## 抖音或短视频怎么做

短视频不要试图讲完整一课。

一条视频只讲一个结果、一个错误或一个概念。

### 推荐结构

~~~text
0～3 秒：问题或结果
3～10 秒：为什么会这样
10～45 秒：三个关键步骤
45～60 秒：正确结果和避坑提醒
结尾：完整教程在哪里
~~~

### 可拆分的短视频题目

- STM32 的 TX 和 RX 为什么要交叉
- ESP-01S 为什么总是重启
- HX711 去皮是什么意思
- 电机为什么不能直接接 GPIO
- 为什么 OneNET 有数据，小程序却显示 0
- MaixCam 为什么识别到了猫却没有进食记录
- 5 g 出粮为什么每次不一样

### 短视频画面

- 使用 9:16 竖屏
- 常用输出为 1080×1920
- 字幕要大
- 一屏不要出现大段代码
- 代码只保留关键的 1～3 行
- 重要物体放在画面中间安全区域

短视频负责吸引兴趣，完整步骤仍然放在 GitHub、博客或长视频。

## 博客怎么做

建议一课对应一篇文章。

### 文章结构

1. 最终效果
2. 本文适合谁
3. 需要的硬件和软件
4. 接线表
5. 操作步骤
6. 正确日志
7. 常见错误
8. 完成检查
9. 下一篇链接

### 标题写法

不要只写：

~~~text
智能喂食器教程 04
~~~

可以写：

~~~text
零基础 STM32：第一次点亮 LED，并理解 GPIO 是什么
~~~

标题包含读者问题和最终结果，更容易被搜索到。

### 博客注意事项

- 代码必须能复制
- 图片下面写图注
- 一张图只表达一个重点
- 不把关键步骤只放在视频里
- 文章开头注明对应 Git 提交号
- 文章结尾链接 GitHub 原文

## 小书怎么做

小书不应只是把 17 篇文章直接拼在一起。

建议分为四部分：

1. 入门准备
2. 本地硬件实验
3. 网络、云端和视觉
4. 系统联调与项目展示

每一部分增加：

- 开篇说明
- 本部分学习目标
- 章节之间的连接说明
- 复习题
- 小练习
- 本部分总结

### 小书需要额外补充

- 封面和版权页
- 项目版本与适用日期
- 目录
- 术语表
- 图片编号
- 代码编号
- 参考资料和第三方许可证
- 索引或问题速查

发布 PDF 或电子书前，应固定一个 Git Tag，确保书中的代码不会随主分支变化。

## 一份内容如何同时发布

以“HX711 称重”为例：

| 形式 | 内容重点 |
| --- | --- |
| GitHub 教程 | 完整步骤和可复制代码 |
| 博客 | 搜索友好的解释和错误对照 |
| 长视频 | 接线、去皮、标定全过程 |
| 抖音 | 解释去皮或重量跳动的一个问题 |
| 小书 | 原理、实验、练习和完整记录 |

不要把相同内容原封不动复制到所有平台。每个平台保留最适合它的表达方式。

~~~text

~~~

文件名包含课程编号，后期查找会容易很多。

## 隐私和安全

录制前隐藏：

- Wi-Fi 名称和密码
- Token 与 Authorization
- AppID 密钥
- 设备名称
- 个人账号、通知和聊天窗口
- 不希望公开的网络地址
- 家庭住址和个人照片

建议为公开教程创建单独的演示账号、演示设备和演示热点。

## 版权

- 不随意使用网络图片
- 背景音乐应有明确使用许可
- 模型文件需要确认许可证
- 第三方代码保留版权说明
- 数据手册优先链接官方来源，不直接重新打包

## 推荐制作顺序

1. 先把 GitHub 教程写准确
2. 按教程重新操作并录制
3. 用录制内容制作长视频
4. 从长视频拆分短视频
5. 将教程改写成博客
6. 内容稳定后整理成小书

不要先追求精美剪辑。先保证步骤真实、结果可复现、声音清楚。
