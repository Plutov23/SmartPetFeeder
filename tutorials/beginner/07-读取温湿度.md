# 第 7 课：读取温度和湿度

## 这一课要完成什么

让 AHT20 读取环境温度和湿度，并显示在串口助手中。

## 需要准备

- AHT20 模块
- STM32
- USART1 调试串口
- 杜邦线

## 接线

| AHT20 | STM32 |
| --- | --- |
| SCL | PB8 |
| SDA | PB9 |
| GND | GND |
| VCC | 按模块规格供电 |

PB8 和 PB9 是项目的硬件 I2C 引脚。

## 什么是 I2C

I2C 是一种让 STM32 与传感器通信的方法。

它主要使用两根信号线：

- SCL：时钟
- SDA：数据

## 添加临时测试代码

打开 <code>Core/Src/main.c</code>。

在 <code>USER CODE BEGIN 2</code> 后加入：

~~~c
AHT20_Init();

while (1)
{
    AHT20_Read(&temp, &humi);
    HAL_Delay(2000);
}
~~~

确保上一课的 OLED 临时测试已经删除。

## 编译和运行

1. 编译并烧录。
2. 打开 USART1，设置 9600。
3. 按复位键。
4. 等待约 2 秒。

## 正确现象

串口反复出现：

~~~text
[AHT20] Read Success - Temp: 25.0 C, Humi: 60.0 %
~~~

实际数字会随环境变化，不需要和示例完全相同。

## 做一个简单验证

用手轻轻握住传感器附近，不要拉扯接线。

等待几秒后，温度或湿度应该有变化。

数值变化方向合理即可，不要求立刻精确。

## 一直显示读取失败

检查：

1. PB8 是否连接 SCL
2. PB9 是否连接 SDA
3. VCC 和 GND
4. 模块是否有 I2C 上拉电阻
5. 模块是否真的是 AHT20

## 数字完全不变化

- 手等待的时间太短
- 传感器没有成功读取
- 串口显示的是旧日志
- 模块可能接触不良

## 想进一步了解

代码中的 <code>0x70</code> 是 STM32 HAL 使用的地址写法，对应常见资料里的 7 位地址 <code>0x38</code>。

第一次学习只需知道这两个数字描述的是同一个 AHT20 地址。
