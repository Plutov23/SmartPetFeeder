# 第 13 课：使用微信小程序

## 这一课要完成什么

在微信开发者工具中打开小程序，并看到 OneNET 的设备数据。

之后再测试 5 g 出粮命令。

## 小程序负责什么

小程序可以：

- 查看温度、湿度和余粮
- 手动出粮
- 设置喂食计划
- 查看进食记录
- 查看 MaixCam 画面

## 安装微信开发者工具

从微信官方渠道安装微信开发者工具。

第一次学习可以使用项目中的测试 AppID 配置。正式发布时需要自己的 AppID。

## 导入项目

选择项目目录：

~~~text
miniapp/wechat
~~~

不要选择整个 SmartPetFeeder 仓库。

## 创建本地配置

复制：

~~~text
config.example.js
~~~

将副本重命名为：

~~~text
config.js
~~~

填写：

- OneNET Product ID
- Device Name
- HTTPS API Authorization
- MaixCam WebSocket 地址

当前只测试云端数据时，MaixCam 地址可以先保留占位值。

## Token 和 Authorization 不一样

- MQTT Token：给设备连接 OneNET
- API Authorization：给小程序调用 OneNET 接口

填反后，小程序通常无法读取数据。

## 编译小程序

点击开发者工具中的编译按钮。

打开首页。

## 正确现象

最多等待约 5 秒，页面显示：

- 温度
- 湿度
- 余粮重量

数字应与 OneNET 控制台接近。

## 页面一直显示 0

检查开发者工具的 Network 和 Console：

1. Product ID 是否正确
2. Device Name 是否正确
3. Authorization 是否有效
4. OneNET 是否已有设备数据
5. 返回属性是否包含 <code>tem</code>、<code>wet</code>、<code>wei</code>

## 测试最小出粮量

确认电机和出粮机构安全后，选择“试出粮 5g”。

同时观察：

- 小程序请求结果
- OneNET 下发
- STM32 USART1 日志
- 电机动作
- 实际出粮重量

平台显示成功，只代表命令已被接受，不代表机械结构一定已经出粮。

## 测试喂食计划

新建一个未来 2 分钟的计划。

确认 USART1 出现计划更新日志。

等待时间到达，检查是否只出粮一次。

STM32 重启后，当前计划会丢失，需要重新同步。

## 安全提醒

当前教学版本把 OneNET Authorization 放在前端配置中。

这适合原型演示，不适合正式公开产品。

正式版本应增加自己的后端，由后端保存平台凭据并限制出粮权限。

## 本地记录

进食记录保存在当前手机或开发者工具的本地缓存中。

清理缓存或换设备后，记录不会自动恢复。

## 这一课的完成标准

- [ ] 小程序能够编译
- [ ] 页面显示 OneNET 数据
- [ ] 5 g 试出粮链路通过
- [ ] 计划能够同步到 STM32
- [ ] 知道平台成功不等于实际出粮成功
- [ ] config.js 没有提交到 Git
