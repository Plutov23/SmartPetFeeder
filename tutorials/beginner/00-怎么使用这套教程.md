# 第 0 课：怎么使用这套教程

## 这一课要完成什么

这一课不接线，也不写代码。

你只需要了解学习方法，并准备一个记录问题的地方。

## 先接受一件事

第一次接触单片机时，看不懂是正常的。

你可能会遇到很多陌生词，例如：

- 引脚
- GPIO
- 串口
- 烧录
- 传感器
- 云平台

不用一次记住。每个词会在真正用到时再解释。

## 准备一个学习记录

可以使用纸质笔记本，也可以新建一个文档。

每完成一课，记录四件事：

~~~text
今天完成了什么：
我看到了什么结果：
我遇到了什么问题：
最后怎么解决的：
~~~

以后系统出现问题时，这份记录会非常有用。

## 教程里的四种提示

### 你要做

这是需要你实际操作的步骤。按照顺序完成，不要跳过。

### 正确现象

这里会告诉你操作成功后应该看到什么。

如果实际现象不同，先不要继续下一步。

### 注意

这里通常与供电、接线、密码或设备安全有关。

必须先看完再操作。

### 想进一步了解

这里解释原理。

第一次学习时可以跳过，不影响继续操作。

## 三条学习规则

### 一次只增加一个模块

例如，先让 STM32 正常运行，再连接 OLED。

不要第一天就把摄像头、电机、传感器和 Wi-Fi 全部接上。

### 一次只修改一个地方

如果程序不能运行，不要同时修改代码、接线和电源。

一次改一个地方，才能知道问题到底在哪里。

### 保存正确结果

每次成功后保存：

- 一张接线照片
- 一张软件截图
- 一份串口文字
- 当前 Git 提交号或教程版本

以后出现问题时，可以退回最后一次成功的状态。

## 遇到问题时怎么提问

不要只说“不能用”。

请准备：

~~~text
我正在学习第几课：
我使用的模块型号：
我做到了哪一步：
教程说应该看到什么：
我实际看到了什么：
串口或软件显示了什么错误：
我已经检查过什么：
~~~

不要公开 Wi-Fi 密码、Token、Authorization 或 AppID 密钥。

## 这一课的完成标准

- [ ] 已准备学习记录
- [ ] 知道一次只增加一个模块
- [ ] 知道实际结果不对时先停止
- [ ] 知道提问时要提供完整现象
- [ ] 知道不能公开密码和设备密钥
