# 第 3 课：安装软件并打开 STM32 工程

## 这一课要完成什么

这一课不接传感器，也不控制电机。

目标只有一个：

> 使用 Keil 打开项目，并看到 0 Error。

0 Error 表示代码成功完成编译。

## 编译是什么意思

STM32 不能直接理解人写的 C 代码。

编译器会把 C 代码转换成 STM32 能够运行的内容。

可以简单理解为：

~~~text
C 代码
  ↓ Keil 编译
STM32 能运行的程序
~~~

这一课只进行编译，还不会把程序写入开发板。

## 需要准备什么

- 一台 Windows 电脑
- Keil MDK-ARM 5
- STM32F1 Device Family Pack
- 已下载的 SmartPetFeeder 项目

后面的烧录课程还需要 ST-Link 和对应驱动，这一课暂时可以不连接开发板。

## 第一步：安装 Keil

安装 Keil MDK-ARM 5。

安装时：

- 使用正常的英文或数字目录
- 记住安装位置
- 安装完成后先启动一次

如果电脑已经安装 Keil，可以直接进入下一步。

## 第二步：安装 STM32F1 支持包

Keil 需要设备支持包，才能认识 STM32F103C8T6。

打开 Keil 的 Pack Installer。

搜索：

~~~text
STM32F1
~~~

安装 STM32F1 Device Family Pack。

如果没有安装，Keil 可能提示找不到设备或头文件。

## 第三步：下载项目

打开 GitHub 仓库：

[SmartPetFeeder](https://github.com/Plutov23/SmartPetFeeder)

第一次使用 GitHub 时，可以：

1. 点击绿色的 Code 按钮。
2. 点击 Download ZIP。
3. 下载完成后解压。
4. 将项目放在容易找到的目录。

不要直接在 ZIP 压缩包里打开工程。

## 第四步：准备本地配置文件

进入：

~~~text
firmware/stm32f103/Core/Inc
~~~

找到：

~~~text
app_config.example.h
~~~

复制一份，并将副本重命名为：

~~~text
app_config.h
~~~

这一课可以保留文件中的 <code>YOUR_WIFI_SSID</code> 等占位文字。

它们不会影响检查代码能否完成编译。

注意：不要删除原来的 <code>app_config.example.h</code>。

## 第五步：打开 Keil 工程

进入：

~~~text
firmware/stm32f103/MDK-ARM
~~~

双击：

~~~text
F103_Feeder.uvprojx
~~~

等待 Keil 打开工程。

左侧应该出现很多文件分组。现在不需要逐个打开。

## 第六步：开始编译

可以使用下面任意一种方法：

- 点击工具栏上的 Build 按钮
- 按键盘 F7

等待下方输出窗口停止滚动。

## 正确现象

输出窗口最后应出现类似结果：

~~~text
0 Error(s), 0 Warning(s)
~~~

最重要的是：

~~~text
0 Error
~~~

这表示工程成功完成编译。

## 如果提示找不到 app_config.h

说明第四步没有完成。

检查：

1. 文件是否叫 <code>app_config.h</code>
2. 文件是否还带有隐藏的 <code>.txt</code> 后缀
3. 文件是否位于 <code>Core/Inc</code>
4. 是否误删了文件内容

## 如果提示找不到编译器

工程原本使用 ARM Compiler 5.06。

如果电脑没有这个编译器：

1. 打开 Project。
2. 打开 Options for Target。
3. 查看当前选择的 ARM Compiler。
4. 选择电脑已经安装的兼容编译器。

先不要修改业务代码来消除编译器错误。

## 如果提示找不到 STM32F1 设备

检查 STM32F1 Device Family Pack 是否已经安装。

关闭并重新打开 Keil，然后再次编译。

## 如果出现很多错误

先看第一条错误。

后面的错误可能只是第一条错误引起的。

不要从最后一条开始处理。

提问时，请复制完整的第一条错误，不要只截取“Build failed”。

## 你不需要现在看懂代码

能够打开工程和成功编译，就已经完成这一课。

后面的课程会从很小的程序开始，逐步解释 LED、串口和传感器。

## 这一课的完成标准

- [ ] 已安装 Keil MDK-ARM 5
- [ ] 已安装 STM32F1 支持包
- [ ] 项目已经完整解压
- [ ] 已创建本地 <code>app_config.h</code>
- [ ] 已打开 <code>F103_Feeder.uvprojx</code>
- [ ] 编译结果为 0 Error
- [ ] 没有修改完整项目的业务代码
