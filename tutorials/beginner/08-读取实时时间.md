# 第 8 课：读取实时时间

## 这一课要完成什么

让 DS1302 保存并输出当前时间。

断开主电源后，只要后备电池正常，它仍会继续计时。

## 接线

| DS1302 | STM32 |
| --- | --- |
| RST / CE | PA6 |
| CLK / SCLK | PA4 |
| DAT / IO | PA5 |
| GND | GND |
| VCC | 按模块规格供电 |

注意：请按这张表接线。不要依赖旧的 CubeMX 标签注释。

## 什么是实时时钟

实时时钟常写作 RTC。

它的作用类似电子手表，即使 STM32 忙着做别的事，也能继续保存年月日和时分秒。

## 第一次设置时间

在 <code>USER CODE BEGIN 2</code> 后加入：

~~~c
DS1302_Init();
DS1302_SetTime(26, 11, 5, 14, 30, 0);

while (1)
{
    DS1302_ReadAndPrintTime();
    HAL_Delay(1000);
}
~~~

把数字换成烧录时的真实时间：

~~~text
年、月、日、时、分、秒
~~~

年份只填写后两位。例如 2026 年填写 26。

## 正确现象

串口每秒输出一次：

~~~text
[RTC] Current Time: 2026-11-05 14:30:01
[RTC] Current Time: 2026-11-05 14:30:02
~~~

秒数应该连续增加。

## 非常重要：只设置一次

确认时间正确后，注释掉设置时间这一行：

~~~c
// DS1302_SetTime(26, 11, 5, 14, 30, 0);
~~~

然后重新编译和烧录。

如果不注释，每次复位都会回到同一个时间。

## 断电保持测试

1. 确认后备电池已正确安装。
2. 记录当前时间。
3. 关闭主电源一分钟。
4. 重新上电。
5. 查看时间是否继续增加。

## 时间不走

- RST、CLK、IO 接错
- 后备电池没有电
- 模块没有供电
- 秒寄存器没有启动

## 每次开机时间都相同

- 设置时间代码没有注释
- 后备电池无电或接触不良
