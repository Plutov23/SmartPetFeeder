# 第 10 课：让步进电机转起来

## 这一课要完成什么

让步进电机转动固定步数，并测量实际出粮重量。

## 安全提醒

电机不能直接连接 STM32。

必须使用 ULN2003 驱动板。

第一次测试时先让电机空转，不要连接出粮机构。

## 接线

| ULN2003 | STM32 |
| --- | --- |
| IN1 | PB4 |
| IN2 | PB5 |
| IN3 | PB6 |
| IN4 | PB7 |
| GND | GND |
| VCC | 按电机规格供电 |

本项目使用 5 V 版本的 28BYJ-48。

确认你手上的电机型号，不要只看外观。

## 添加临时测试代码

在 <code>USER CODE BEGIN 2</code> 后加入：

~~~c
StepperMotor_Init();
StepperMotor_SetDirection(CLOCKWISE);
StepperMotor_SetSpeed(2000);
StepperMotor_Step(200);

while (StepperMotor_IsRunning())
{
    HAL_Delay(10);
}

StepperMotor_Stop();

while (1)
{
    HAL_Delay(100);
}
~~~

## 正确现象

- 驱动板指示灯按顺序变化
- 电机连续转动一小段
- 结束后电机停止
- STM32 没有重启

## 电机只抖不转

检查：

1. IN1 到 IN4 顺序
2. 电机插头是否牢固
3. 电源电流是否足够
4. 速度是否太快
5. 机构是否卡住

可以把速度数字改大，例如 3000。数字越大，转动越慢。

## 方向错误

将：

~~~c
CLOCKWISE
~~~

改为：

~~~c
COUNTER_CLOCKWISE
~~~

## 电机一转，STM32 就重启

通常是电源问题：

- 电机和 STM32 共用的电源太弱
- 电机启动时电压下降
- GND 接线不可靠
- 电机堵转

先断开机械负载，再检查供电。

## 标定每克需要多少步

连接实际出粮机构后：

1. 执行固定步数 N。
2. 收集落下的宠物粮。
3. 用已标定的秤测量重量 W。
4. 计算每克步数。

~~~text
每克步数 = N ÷ W
~~~

至少重复 5 次，再取平均值。

## 写入参数

手动出粮使用 <code>app_config.h</code> 中的：

~~~c
#define FEEDER_STEPS_PER_GRAM 50
~~~

定时出粮当前还在 <code>schedule.c</code> 中保存了另一个 <code>STEPS_PER_GRAM</code>。

两个值必须保持一致。

## 实验完成后

删除本课临时测试代码。

保存：

- 空载转动视频
- 5 次标定结果
- 最终每克步数
