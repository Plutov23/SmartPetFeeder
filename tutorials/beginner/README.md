# SmartPetFeeder 零基础入门

这套教程写给第一次接触单片机、电路和物联网的同学。

你不需要提前学会 C 语言，也不需要先理解所有英文缩写。遇到新名词时，教程会马上解释。

## 学完后你能知道什么

完成整套教程后，你应该能够：

- 说出智能喂食器由哪些模块组成
- 看懂简单的接线表
- 使用 Keil 打开和编译 STM32 工程
- 使用串口查看设备运行信息
- 读取温湿度、时间和重量
- 控制步进电机出粮
- 理解设备怎样把数据发送到云平台
- 使用微信小程序查看和控制设备
- 理解 MaixCam 怎样识别猫狗
- 遇到故障时知道先检查哪里

重点不是背代码，而是理解每一部分在做什么。

## 怎么学习

一次只学习一课。

不要提前把所有模块都接上。每完成一个小实验，再增加一个模块。

每一课都会告诉你：

1. 这一课要完成什么
2. 需要准备什么
3. 要做哪些操作
4. 正确结果是什么
5. 失败时先检查什么

## 学习时间

不要要求自己一天完成。

建议每次学习 30～60 分钟。完成一课后，保存照片、日志和笔记，再开始下一课。

如果一节卡住超过 30 分钟，先停下来休息。重新检查电源、接线和当前步骤，不要同时修改很多地方。

## 安全规则

- 接线前先断电
- 不知道模块电压时不要通电
- 电机不能直接连接 STM32 引脚
- 不要用手触摸正在发热的模块
- 出现异味、冒烟或明显发热时立即断电
- 不要把 Wi-Fi 密码和设备密钥发到公开网站
- 原型设备不要在无人看管时长期运行
