# 第 4 课：点亮第一个 LED

## 这一课要完成什么

让 STM32 控制一个 LED 闪烁。

这是第一个真正运行在 STM32 上的小实验。

## 需要准备

- STM32F103C8T6 开发板
- ST-Link
- 一个 LED
- 一个 220 Ω～1 kΩ 电阻
- 杜邦线

本项目使用 PB15 控制 LED。不要假设开发板自带的 LED 也是 PB15。

## LED 为什么需要电阻

电阻用来限制电流。

LED 直接连接电源或 GPIO，可能损坏 LED 或 STM32 引脚。

## 接线

~~~text
STM32 PB15 → 电阻 → LED 正极
LED 负极 → GND
~~~

LED 两只脚通常一长一短：

- 长脚通常是正极
- 短脚通常是负极

不同 LED 可能不一样，不确定时先查型号。

## 连接 ST-Link

| ST-Link | STM32 |
| --- | --- |
| SWDIO | SWDIO |
| SWCLK | SWCLK |
| GND | GND |
| 3.3 V | 按开发板供电方式连接 |

接线前断电。

## 添加临时测试代码

打开 <code>Core/Src/main.c</code>。

找到：

~~~c
/* USER CODE BEGIN 2 */
~~~

在它下面临时加入：

~~~c
for (int i = 0; i < 6; i++)
{
    HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
    HAL_Delay(500);
}
~~~

不要删除 <code>USER CODE</code> 标记。

## 编译和烧录

1. 按 F7 编译。
2. 确认 0 Error。
3. 点击 Download。
4. 等待烧录完成。
5. 按开发板复位键。

## 正确现象

LED 每隔约半秒改变一次状态，共变化 6 次。

如果第一次是灭的也没关系。不同接法的有效电平可能相反，只要能够稳定切换就说明 PB15 正在工作。

## LED 完全不亮

按顺序检查：

1. 工程是否成功烧录
2. LED 正负极是否接反
3. 是否连接 PB15
4. 是否串联电阻
5. GND 是否连接
6. LED 是否损坏

可以把 LED 反过来再试一次，但必须先断电。

## LED 一直亮

- 检查代码是否放在 <code>USER CODE BEGIN 2</code> 后面
- 检查是否重新编译和烧录
- 检查是否按了复位键
- 确认打开的是当前项目

## 实验完成后

保留一张 LED 接线照片。

然后删除本课加入的 <code>for</code> 循环，重新编译一次。下一课会使用同一个工程测试串口。
