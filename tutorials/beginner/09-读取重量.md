# 第 9 课：读取重量

## 这一课要完成什么

让压力传感器和 HX711 显示重量。

这一课包含两个动作：

- 去皮
- 标定

## 去皮是什么意思

把空料斗当前的重量当作 0 g，就叫去皮。

电子秤上的“TARE”按钮也是这个作用。

## 标定是什么意思

用一个已知重量的物体，告诉程序“这些原始数字等于多少克”，就叫标定。

## STM32 与 HX711 接线

| HX711 | STM32 |
| --- | --- |
| DOUT / DT | PA11 |
| SCK / CLK | PA12 |
| GND | GND |
| VCC | 按模块规格供电 |

压力传感器连接 HX711 的 E+、E-、A+、A-。

不同厂家的线色可能不同。请查看传感器说明，不要只根据颜色连接。

## 机械安装

压力传感器必须正确受力：

- 固定端不能移动
- 受力端连接料斗
- 料斗不能碰到外壳
- 电线不能拉扯受力端

机械安装不稳定，软件也无法得到稳定重量。

## 添加临时测试代码

在 <code>USER CODE BEGIN 2</code> 后加入：

~~~c
HX711_Init();

while (1)
{
    weight = HX711_Get_Weight();
    APP_LOG("LEARN", "Weight: %ld g", weight);
    HAL_Delay(1000);
}
~~~

开机时保持料斗为空，因为程序会自动去皮。

## 正确现象

串口先显示去皮：

~~~text
[WEIGHT] Manual taring start...
[WEIGHT] Tare done! New Offset: ...
~~~

之后每秒显示重量。

空载时应该接近 0 g。

## 标定步骤

1. 空载开机并完成去皮。
2. 放上一个已知重量的物体。
3. 等待数字稳定。
4. 记录当前原始值和零点。
5. 使用下面公式计算比例系数。

~~~text
比例系数 =（有砝码的原始值 - 空载原始值）÷ 砝码克数
~~~

将结果写入 <code>Core/Src/HX711.c</code> 的 <code>HX711_Scale</code>。

第一次标定建议让老师或有经验的同学一起完成。

## 放上物体仍显示 0

- 比例系数方向错误
- 传感器线接错
- 去皮时物体没有拿走
- 料斗没有把力量传给传感器

## 数字一直跳

- 传感器没有固定
- 电线正在拉扯传感器
- 电源不稳定
- 电机产生振动
- 当前程序没有运行时滤波

本课不要让电机转动。

## 程序停在去皮开始

当前驱动会等待 HX711 准备完成。

检查供电、PA11、PA12 和 GND。

## 验证标定

至少测试：

- 空载
- 一个较轻物体
- 标定物体
- 接近实际最大粮量的物体

不要只在一个重量点确认。

## 实验完成后

保存标定系数和测试记录。

删除临时测试循环，保留你计算得到的 <code>HX711_Scale</code>。

更详细的标定说明见[技术参考版](../03-HX711称重与标定.md)。
