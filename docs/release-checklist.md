# 公开发布检查清单

## 源码

- [ ] STM32 工程可以从干净目录编译。
- [ ] MaixCam 程序通过 Python 语法检查并能在目标设备启动。
- [ ] 微信小程序能够在开发者工具编译。
- [ ] 没有提交 IDE 私有文件、编译产物和历史安装包。

## 安全

- [ ] 没有真实 Wi-Fi 名称和密码。
- [ ] 没有 OneNET Token、Authorization 或设备密钥。
- [ ] 没有正式微信 AppID 或后台密钥。
- [ ] 所有曾进入旧 Git 历史的凭据已吊销并重新生成。
- [ ] 已检查图片、日志和文档中的个人信息。

## 版权

- [ ] 只发布自己拥有权利或许可证允许再分发的文件。
- [ ] 第三方代码保留版权和许可证文本。
- [ ] 数据手册和教程资料使用官方链接，不直接重新打包。
- [ ] 模型文件的来源和许可证已经确认。

## 文档

- [ ] README 的接线、路径和配置字段与源码一致。
- [ ] BOM、协议和已知限制完整。
- [ ] 至少由一名未参与开发的人按照文档完成部署。
- [ ] 发布版本包含更新记录和 Git Tag。
